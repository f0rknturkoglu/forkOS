## 2. Signal taxonomy

- **E/U/D**: employer publication / board update-republication / observed or unknown. Board insertion never upgrades freshness to employer date. Absolute JobPosting datePosted is source declaration, not independent proof of original employer history.
- **Full source body** means untruncated job-specific text exposed by this public surface. It does not prove equivalence to an original employer document. Preview and full-JD coverage are never inferred from character counts.
- **ID**: native ID/GUID first, then specific canonical posting URL/token; URL-derived hashes are fallback identity, not native IDs. Specific apply href is stored without following forbidden clickouts. Generic careers/apply roots are not strong dedup evidence.
- **Optional signals**: salary min/max/currency/period, skills/tools, seniority/experience, employment/workload/hours/duration, declared working language/level, scope/timezone/right-to-work, visa/relocation Yes/No/unknown, company/requisition/original source, deadline/expiry. Absent fields stay unknown, never No or global.
- **Authority**: employer > native > meta. Source facts retain deterministic provenance. Board sponsorship/English tags are kept outside employer-promise scoring. No ranking weights changed.
- **Pipeline**: source → Job fields + Source facts → job_to_raw (apply/source_authority/description) → canonical raw.forkjob + source observations → scoring_tags/detect → candidate matching. Deadlines are retained as source evidence, not invented Opportunity deadlines.
